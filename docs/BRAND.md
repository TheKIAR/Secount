# Secount Brand Guide

## Identity

**Secount** combines **Se**cret + **Count**: a private countdown studio for moments that should arrive at the right time.

Tagline: **Count what matters.**

## Visual language

- Primary rose: `#FF5D97`
- Secondary violet: `#7C6CFF`
- Deep background: `#17102B`
- Light mark: `#FFF3F7`
- The mark combines a countdown ring with an hourglass to communicate **time + anticipation + privacy**.

## Assets

- `assets/secount-logo.svg` — full wordmark for README, portfolio and product pages.
- `assets/secount-mark.svg` — standalone mark.
- `android/androidApp/src/main/res/drawable/secount_mark.xml` — Android splash/launcher mark.
- `android/androidApp/src/main/res/drawable/ic_stat_secount.xml` — monochrome Android notification icon.
- `android/androidApp/src/main/res/mipmap-anydpi-v26/` — adaptive Android launcher icons.

## Usage

Keep the mark clear and simple. Prefer the deep violet background when presenting the full wordmark. Do not recolor the notification icon; Android requires a monochrome notification glyph.

The Windows `.ico`/`.png` packaging assets remain a separate binary asset and should be regenerated from the approved mark before a desktop release refresh.
